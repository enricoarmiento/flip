# Flip

Assistente per Mac e Windows: tieni premuto un tasto, parla, e lui vede lo schermo, risponde, indica e agisce. Sul Mac vive nella notch.

**Scarica e istruzioni:** https://enricoarmiento.github.io/flip/

- Mac: macOS 14 o successivo, solo Apple Silicon. Versione di prova, non ancora firmata con un account sviluppatore Apple: alla prima apertura va autorizzata da Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.
- Windows: Windows 10 o 11 a 64 bit. Se compare «PC protetto da Windows», scegli Ulteriori informazioni → Esegui comunque.

Questo repository contiene la pagina di download (`index.html` con le sue immagini) e le versioni dell'app. Il codice sorgente non è pubblico.
