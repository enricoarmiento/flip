# ClinicalEye

Assistente per Mac che vive nella notch: tieni premuto un tasto, parla, e lui vede lo schermo, risponde, indica e agisce.

**Scarica e istruzioni:** https://enricoarmiento.github.io/clinical-eye/

- macOS 14 o successivo, solo Apple Silicon.
- Versione di prova, non ancora firmata con un account sviluppatore Apple: alla prima apertura va autorizzata da Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.

Questo repository contiene la pagina di download e le versioni dell'app. Il codice sorgente non è pubblico.
